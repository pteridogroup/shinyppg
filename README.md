# shinyppg

**NO LONGER UNDER DEVELOPMENT**

This repo used to be a [Shiny](https://shiny.posit.co/) app to view the [Pteridophyte Phylogeny Group (PPG)](https://pteridogroup.github.io/) taxonomic database.

It has been retired in favor of a solution that does not need Shiny or R.
